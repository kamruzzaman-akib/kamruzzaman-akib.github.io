Troubleshooting “Unable to delete C:\wim”

When a C:\wim folder can't be deleted it's usually a WIM image that was never unmounted. Use DISM to find, discard and clean up the mount, then delete the folder.

By Kamruzzaman Akib · 2 min read

  • DISM
  • WIM
  • Troubleshooting
About this article. I originally wrote this guide for my company’s internal knowledge base. This public version has company names, colleagues’ names and email addresses, internal domains and system details removed. Screenshots are shown at full size: click any of them to enlarge. If you can't delete a C:\wim folder, the cause is almost always a WIM image that is still mounted (it wasn't unmounted properly), plus permissions or files in use. I hit this on several laptops after image servicing work.

Prerequisites

  • An account with administrator rights on the computer.
  • A bootable Windows USB stick, used for unmounting the image.

Fix

  1. Insert the bootable USB drive.
  2. Open Command Prompt as administrator.
  3. Check for mounted images: 
    DISM /Get-MountedWimInfo
  4. If any images are listed, note the Mount Directory. It should be C:\wim or similar.
  5. Unmount the image and discard changes (replace the path if yours differs): 
    DISM /Unmount-Wim /MountDir:"C:\wim" /discard
    • /discard throws away any changes made to the mounted image.
    • /commit would save the changes. Don't use it here: it tries to find the original source the image was mounted from (often an old USB stick) and fails.
  6. Clean up any leftover mounts: 
    DISM /Cleanup-Wim
  7. Delete the C:\wim folder again. It should now delete.
