Install Ubuntu 24.04 LTS with full-disk encryption from a bootable USB

Build an Ubuntu USB stick with Rufus and install Ubuntu Desktop 24.04 LTS on an Intel/AMD laptop with LVM + LUKS encryption, ready to be enrolled in Intune.

By Kamruzzaman Akib · 7 min read

  • Ubuntu
  • Linux
  • Rufus
  • LUKS
  • Encryption
About this article. I originally wrote this guide for my company’s internal knowledge base. This public version has company names, colleagues’ names and email addresses, internal domains and system details removed. Screenshots are shown at full size: click any of them to enlarge. Only the parts that showed people or company information are blurred. Example addresses use Microsoft’s fictional contoso.com domain.

Some engineers needed Linux laptops that still met our security baseline. This guide gives a repeatable, encrypted Ubuntu install that can then be enrolled in Microsoft Intune and Defender.

Part 1: Create the bootable USB

  1. Download Ubuntu Desktop (LTS, Intel or AMD 64-bit) from ubuntu.com/download/desktop.
  2. Download Rufus from rufus.ie and insert a USB stick (8 GB or more).
  3. Open Rufus.
  4. Click Select and choose the Ubuntu ISO.
  5. Set a Volume label and click Start.
  6. Rufus detects an ISOHybrid image. Keep Write in ISO Image mode (Recommended) and click OK. Then confirm the warning that the stick will be erased.
  7. Done!

Part 2: Install Ubuntu

  1. Shut down the laptop with the USB stick inserted, then power it on.
  2. On a ThinkPad, keep pressing Enter at “To interrupt normal startup”, then press F12 and choose the USB drive. If you're asked for a BIOS password, contact IT.
  3. Choose Try or Install Ubuntu.
  4. Wait for the installer to start. Choose your language, skip accessibility, choose a keyboard layout and connect to the internet.
  5. If the installer offers an update, click Update now, then close the installer when asked.
  6. Double-click Install Ubuntu on the desktop and repeat the language/keyboard/network steps.
  7. Keep Interactive installation.
  8. Keep Default selection for apps.
  9. Tick both recommended proprietary software options. They install the drivers for Wi-Fi, audio and graphics.
  10. Under Erase disk and install Ubuntu, click Advanced features…
  11. Choose Use LVM and encryption, click OK and then Next.
  12. Create a strong passphrase (for example two capitalised words joined by a special character, at least 12 characters in total). Store it in your password manager. If it's lost, the data can't be recovered.
  13. Create the local administrator account using your organisation's naming standard and password policy.
  14. Choose your time zone.
  15. Review your choices (you should see LUKS (LVM) under disk encryption) and click Install.
  16. Ubuntu installs.
  17. When it's finished, click Restart now. Ubuntu is ready to be enrolled in Intune.
