Automation

PowerShell script library

Scripts I wrote to take slow, repetitive admin work off my plate, cleaned up for public use. Most use the Microsoft Graph PowerShell SDK; the rest use the SharePoint Online and Active Directory modules. They all come with built-in help, and every script that changes something supports a -WhatIf dry run.

Before you run any of them
  • Read the built-in help first: Get-Help .\Export-BitLockerKeys.ps1 -Full
  • Install the Graph SDK once with Install-Module Microsoft.Graph -Scope CurrentUser. Each script checks for the modules it needs and says which one is missing.
  • Try them in a test or non-production tenant, and use -WhatIf before any real change.
  • If Windows blocks the file, see Fix “running scripts is disabled on this system”.

Add-LicensesFromCsv.ps1

Bulk assign a Microsoft 365 licence from a CSV

Download Read the guide

Reads UPNs from a CSV, lets you pick a licence in a grid (with the number still available) and assigns it to everyone who doesn’t have it yet. Skips users with no usage location and ends with a summary.

Graph permissions: LicenseAssignment.ReadWrite.All, User.Read.All, Organization.Read.All
Admin role: License Administrator or User Administrator

View the code (115 lines)
<#
.SYNOPSIS
    Assigns one Microsoft 365 licence to every user listed in a CSV file.

.DESCRIPTION
    Reads user principal names (UPNs) from a CSV file, lets you pick a licence (SKU)
    from the tenant in a grid, then assigns it to each user who does not already have it.

    Users who already have the licence are skipped. Users with no usage location are
    skipped too, because Microsoft 365 cannot assign a licence without one.

    Run it with -WhatIf first to see what would change without changing anything.

.PARAMETER CsvPath
    Path to the CSV file. It needs a column named UPN (or UserPrincipalName).

.EXAMPLE
    .\Add-LicensesFromCsv.ps1 -CsvPath .\users.csv -WhatIf
    Dry run: shows which users would get the licence.

.EXAMPLE
    .\Add-LicensesFromCsv.ps1 -CsvPath .\users.csv
    Assigns the licence you pick to every user in users.csv.

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Users,
                  Microsoft.Graph.Identity.DirectoryManagement
    Permissions : LicenseAssignment.ReadWrite.All, User.Read.All, Organization.Read.All (delegated)
    Admin role  : License Administrator or User Administrator
    The licence picker uses Out-GridView, which needs Windows.
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Users, Microsoft.Graph.Identity.DirectoryManagement

[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)]
    [ValidateScript({ Test-Path -Path $_ -PathType Leaf })]
    [string]$CsvPath
)

# --- Read and check the CSV -------------------------------------------------
$rows = @(Import-Csv -Path $CsvPath)
if ($rows.Count -eq 0) {
    throw "The CSV file '$CsvPath' is empty."
}
$upnColumn = $rows[0].PSObject.Properties.Name |
    Where-Object { $_ -in 'UPN', 'UserPrincipalName' } |
    Select-Object -First 1
if (-not $upnColumn) {
    throw 'The CSV file needs a column named UPN or UserPrincipalName.'
}

# --- Connect to Microsoft Graph ---------------------------------------------
Connect-MgGraph -Scopes 'LicenseAssignment.ReadWrite.All', 'User.Read.All', 'Organization.Read.All' -NoWelcome -ErrorAction Stop

# --- Pick the licence --------------------------------------------------------
$sku = Get-MgSubscribedSku -ErrorAction Stop |
    Select-Object SkuPartNumber, SkuId, ConsumedUnits,
        @{ Name = 'Available'; Expression = { $_.PrepaidUnits.Enabled - $_.ConsumedUnits } } |
    Out-GridView -Title 'Select the licence to assign' -OutputMode Single

if (-not $sku) {
    Write-Warning 'No licence selected. Nothing was changed.'
    return
}
Write-Host "Selected licence: $($sku.SkuPartNumber) ($($sku.SkuId))" -ForegroundColor Cyan

# --- Assign the licence to each user ----------------------------------------
$assigned = 0; $skipped = 0; $failed = 0

foreach ($row in $rows) {
    $upn = "$($row.$upnColumn)".Trim()
    if (-not $upn) { continue }

    try {
        $user = Get-MgUser -UserId $upn -Property Id, UserPrincipalName, UsageLocation, AssignedLicenses -ErrorAction Stop
    } catch {
        Write-Warning "$upn : could not find or read this user. $($_.Exception.Message)"
        $failed++
        continue
    }

    if ($user.AssignedLicenses.SkuId -contains $sku.SkuId) {
        Write-Host "$upn already has $($sku.SkuPartNumber). Skipped." -ForegroundColor DarkGray
        $skipped++
        continue
    }

    if (-not $user.UsageLocation) {
        Write-Warning "$upn has no usage location, so a licence cannot be assigned. Set one and run the script again."
        $skipped++
        continue
    }

    if ($PSCmdlet.ShouldProcess($upn, "Assign licence $($sku.SkuPartNumber)")) {
        $body = @{
            addLicenses    = @(@{ skuId = $sku.SkuId })
            removeLicenses = @()
        } | ConvertTo-Json -Depth 5

        try {
            Invoke-MgGraphRequest -Method POST -Uri "https://graph.microsoft.com/v1.0/users/$($user.Id)/assignLicense" `
                -Body $body -ContentType 'application/json' -ErrorAction Stop | Out-Null
            Write-Host "$upn : assigned $($sku.SkuPartNumber)" -ForegroundColor Green
            $assigned++
        } catch {
            Write-Warning "$upn : could not assign the licence. $($_.Exception.Message)"
            $failed++
        }
    }
}

Write-Host ''
Write-Host "Done. Assigned: $assigned   Skipped: $skipped   Failed: $failed" -ForegroundColor Cyan
Remove-LicensesFromCsv.ps1

Bulk remove a Microsoft 365 licence from a CSV

Download Read the guide

The reverse: removes the chosen licence from every user in the CSV. It spots licences that come from group-based licensing and tells you instead of failing. I used this approach to reclaim hundreds of licences after a tenant integration.

Graph permissions: LicenseAssignment.ReadWrite.All, User.Read.All, Organization.Read.All
Admin role: License Administrator or User Administrator

View the code (118 lines)
<#
.SYNOPSIS
    Removes one Microsoft 365 licence from every user listed in a CSV file.

.DESCRIPTION
    Reads user principal names (UPNs) from a CSV file, lets you pick a licence (SKU)
    from the tenant in a grid, then removes it from each user who has it.

    Users who do not have the licence are skipped. Licences that a user gets through
    group-based licensing cannot be removed one user at a time, so those users are
    skipped with a message: remove them from the licensing group instead.

    Run it with -WhatIf first to see what would change without changing anything.

.PARAMETER CsvPath
    Path to the CSV file. It needs a column named UPN (or UserPrincipalName).

.EXAMPLE
    .\Remove-LicensesFromCsv.ps1 -CsvPath .\leavers.csv -WhatIf
    Dry run: shows which users would lose the licence.

.EXAMPLE
    .\Remove-LicensesFromCsv.ps1 -CsvPath .\leavers.csv
    Removes the licence you pick from every user in leavers.csv.

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Users,
                  Microsoft.Graph.Identity.DirectoryManagement
    Permissions : LicenseAssignment.ReadWrite.All, User.Read.All, Organization.Read.All (delegated)
    Admin role  : License Administrator or User Administrator
    The licence picker uses Out-GridView, which needs Windows.
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Users, Microsoft.Graph.Identity.DirectoryManagement

[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)]
    [ValidateScript({ Test-Path -Path $_ -PathType Leaf })]
    [string]$CsvPath
)

# --- Read and check the CSV -------------------------------------------------
$rows = @(Import-Csv -Path $CsvPath)
if ($rows.Count -eq 0) {
    throw "The CSV file '$CsvPath' is empty."
}
$upnColumn = $rows[0].PSObject.Properties.Name |
    Where-Object { $_ -in 'UPN', 'UserPrincipalName' } |
    Select-Object -First 1
if (-not $upnColumn) {
    throw 'The CSV file needs a column named UPN or UserPrincipalName.'
}

# --- Connect to Microsoft Graph ---------------------------------------------
Connect-MgGraph -Scopes 'LicenseAssignment.ReadWrite.All', 'User.Read.All', 'Organization.Read.All' -NoWelcome -ErrorAction Stop

# --- Pick the licence --------------------------------------------------------
$sku = Get-MgSubscribedSku -ErrorAction Stop |
    Select-Object SkuPartNumber, SkuId, ConsumedUnits,
        @{ Name = 'Available'; Expression = { $_.PrepaidUnits.Enabled - $_.ConsumedUnits } } |
    Out-GridView -Title 'Select the licence to remove' -OutputMode Single

if (-not $sku) {
    Write-Warning 'No licence selected. Nothing was changed.'
    return
}
Write-Host "Selected licence: $($sku.SkuPartNumber) ($($sku.SkuId))" -ForegroundColor Cyan

# --- Remove the licence from each user --------------------------------------
$removed = 0; $skipped = 0; $failed = 0

foreach ($row in $rows) {
    $upn = "$($row.$upnColumn)".Trim()
    if (-not $upn) { continue }

    try {
        $user = Get-MgUser -UserId $upn -Property Id, UserPrincipalName, AssignedLicenses, LicenseAssignmentStates -ErrorAction Stop
    } catch {
        Write-Warning "$upn : could not find or read this user. $($_.Exception.Message)"
        $failed++
        continue
    }

    if ($user.AssignedLicenses.SkuId -notcontains $sku.SkuId) {
        Write-Host "$upn does not have $($sku.SkuPartNumber). Skipped." -ForegroundColor DarkGray
        $skipped++
        continue
    }

    # A licence that only comes from a group cannot be removed from the user directly.
    $states = @($user.LicenseAssignmentStates | Where-Object { $_.SkuId -eq $sku.SkuId })
    if ($states.Count -gt 0 -and -not ($states | Where-Object { -not $_.AssignedByGroup })) {
        Write-Warning "$upn gets $($sku.SkuPartNumber) from a group. Remove the user from that group instead."
        $skipped++
        continue
    }

    if ($PSCmdlet.ShouldProcess($upn, "Remove licence $($sku.SkuPartNumber)")) {
        $body = @{
            addLicenses    = @()
            removeLicenses = @($sku.SkuId)
        } | ConvertTo-Json -Depth 5

        try {
            Invoke-MgGraphRequest -Method POST -Uri "https://graph.microsoft.com/v1.0/users/$($user.Id)/assignLicense" `
                -Body $body -ContentType 'application/json' -ErrorAction Stop | Out-Null
            Write-Host "$upn : removed $($sku.SkuPartNumber)" -ForegroundColor Green
            $removed++
        } catch {
            Write-Warning "$upn : could not remove the licence. $($_.Exception.Message)"
            $failed++
        }
    }
}

Write-Host ''
Write-Host "Done. Removed: $removed   Skipped: $skipped   Failed: $failed" -ForegroundColor Cyan

Export-BitLockerKeys.ps1

Export every BitLocker recovery key, with device names

Download Read the guide

Pulls every recovery key stored in Entra ID into one CSV and matches each to a device name from Intune, falling back to Entra ID. Warns about keys it couldn’t read and reminds you to store the file securely.

Graph permissions: BitlockerKey.Read.All, DeviceManagementManagedDevices.Read.All, Device.Read.All
Admin role: Cloud Device Administrator, Helpdesk Administrator, Intune Administrator, Security Administrator, Security Reader or Global Reader

View the code (104 lines)
<#
.SYNOPSIS
    Exports every BitLocker recovery key stored in Microsoft Entra ID to a CSV file,
    with the device name next to each key.

.DESCRIPTION
    The Intune and Entra admin centres show recovery keys one device at a time.
    This script lists every BitLocker recovery key backed up to Microsoft Entra ID,
    reads each key, and matches it to a device name: first from Intune managed
    devices, then from Entra ID devices for anything Intune no longer manages.

    Every key that is read is recorded in the Entra ID audit log (KeyManagement).
    The output file contains recovery keys: store it somewhere secure, limit who
    can open it, and delete it when you no longer need it.

.PARAMETER OutputPath
    Where to save the CSV file. Default: BitLockerKeys-<date>.csv in your Documents folder.

.EXAMPLE
    .\Export-BitLockerKeys.ps1

.EXAMPLE
    .\Export-BitLockerKeys.ps1 -OutputPath 'D:\Secure\BitLockerKeys.csv'

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Identity.SignIns,
                  Microsoft.Graph.DeviceManagement, Microsoft.Graph.Identity.DirectoryManagement
    Permissions : BitlockerKey.Read.All, DeviceManagementManagedDevices.Read.All, Device.Read.All (delegated)
    Admin role  : one of Cloud Device Administrator, Helpdesk Administrator, Intune Administrator,
                  Security Administrator, Security Reader or Global Reader
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Identity.SignIns, Microsoft.Graph.DeviceManagement, Microsoft.Graph.Identity.DirectoryManagement

[CmdletBinding()]
param(
    [string]$OutputPath = (Join-Path -Path ([Environment]::GetFolderPath('MyDocuments')) -ChildPath ('BitLockerKeys-{0:yyyy-MM-dd}.csv' -f (Get-Date)))
)

Connect-MgGraph -Scopes 'BitlockerKey.Read.All', 'DeviceManagementManagedDevices.Read.All', 'Device.Read.All' -NoWelcome -ErrorAction Stop

# --- 1. Build a lookup table: Entra device ID -> device name -----------------
$deviceNames = @{}

Write-Host 'Reading Intune managed devices...' -ForegroundColor Cyan
try {
    Get-MgDeviceManagementManagedDevice -All -Property DeviceName, AzureADDeviceId -ErrorAction Stop |
        Where-Object { $_.AzureADDeviceId -and $_.AzureADDeviceId -ne '00000000-0000-0000-0000-000000000000' } |
        ForEach-Object { $deviceNames[$_.AzureADDeviceId] = $_.DeviceName }
} catch {
    Write-Warning "Could not read Intune devices: $($_.Exception.Message)"
}

Write-Host 'Reading Entra ID devices...' -ForegroundColor Cyan
try {
    Get-MgDevice -All -Property DeviceId, DisplayName -ErrorAction Stop |
        Where-Object { $_.DeviceId -and -not $deviceNames.ContainsKey($_.DeviceId) } |
        ForEach-Object { $deviceNames[$_.DeviceId] = $_.DisplayName }
} catch {
    Write-Warning "Could not read Entra ID devices: $($_.Exception.Message)"
}
Write-Host "Found names for $($deviceNames.Count) devices." -ForegroundColor Green

# --- 2. List every recovery key, then read each key value --------------------
$keys = @(Get-MgInformationProtectionBitlockerRecoveryKey -All -ErrorAction Stop)
Write-Host "Found $($keys.Count) recovery keys. Reading each one..." -ForegroundColor Cyan

$i = 0
$results = foreach ($k in $keys) {
    $i++
    Write-Progress -Activity 'Reading BitLocker recovery keys' -Status "$i of $($keys.Count)" -PercentComplete (100 * $i / $keys.Count)

    $recoveryKey = $null
    try {
        # The key value is only returned when it is asked for explicitly.
        $recoveryKey = (Get-MgInformationProtectionBitlockerRecoveryKey -BitlockerRecoveryKeyId $k.Id -Property key -ErrorAction Stop).Key
    } catch {
        Write-Warning "Could not read key $($k.Id) (device $($k.DeviceId)): $($_.Exception.Message)"
    }

    [PSCustomObject]@{
        DeviceName  = if ($k.DeviceId -and $deviceNames.ContainsKey($k.DeviceId)) { $deviceNames[$k.DeviceId] } else { 'Unknown device' }
        DeviceId    = $k.DeviceId
        KeyId       = $k.Id
        VolumeType  = $k.VolumeType
        Created     = $k.CreatedDateTime
        RecoveryKey = $recoveryKey
    }
}
Write-Progress -Activity 'Reading BitLocker recovery keys' -Completed

# --- 3. Save the results ------------------------------------------------------
$folder = Split-Path -Path $OutputPath -Parent
if ($folder -and -not (Test-Path -Path $folder)) {
    New-Item -Path $folder -ItemType Directory | Out-Null
}
$results | Sort-Object DeviceName, Created | Export-Csv -Path $OutputPath -NoTypeInformation -Encoding UTF8

$missing = @($results | Where-Object { -not $_.RecoveryKey }).Count
Write-Host "Saved $($results.Count) keys to $OutputPath" -ForegroundColor Green
if ($missing -gt 0) {
    Write-Warning "$missing keys could not be read. Check that your account has one of the admin roles listed in the notes."
}
Write-Warning 'This file contains BitLocker recovery keys. Keep it somewhere secure and delete it when you are done.'

Get-UserGroupMembership.ps1

List every group a user belongs to

Download

Answers “why can (or can’t) this person see that?”. Lists a user’s groups with the type of each one (security, Microsoft 365, distribution list or mail-enabled security) and whether membership is dynamic. Add -Transitive for nested groups and -OutputPath to save a CSV.

Graph permissions: User.Read.All, GroupMember.Read.All
Admin role: Any admin role that can read users and groups, such as Global Reader

View the code (98 lines)
<#
.SYNOPSIS
    Lists the groups a user belongs to in Microsoft Entra ID, with the type of each group.

.DESCRIPTION
    Useful when you need to know why someone has, or doesn't have, access to an app,
    a policy or a mailbox. For each group it shows the name, the type (security,
    Microsoft 365, distribution list or mail-enabled security), whether membership is
    dynamic, and the group ID.

    By default it lists direct memberships. Add -Transitive to include groups the user
    is in through another group (nested groups).

.PARAMETER UserPrincipalName
    The user to look up. You are asked for it if you leave it out.

.PARAMETER Transitive
    Include nested group memberships.

.PARAMETER OutputPath
    Optional. Also saves the list to this CSV file.

.EXAMPLE
    .\Get-UserGroupMembership.ps1 -UserPrincipalName alex.wilber@contoso.com

.EXAMPLE
    .\Get-UserGroupMembership.ps1 alex.wilber@contoso.com -Transitive -OutputPath .\alex-groups.csv

.NOTES
    Author      : Kamruzzaman Akib
    Module      : Microsoft.Graph.Authentication
    Permissions : User.Read.All, GroupMember.Read.All (delegated)
    Directory roles and administrative units are left out; only groups are listed.
#>
#Requires -Modules Microsoft.Graph.Authentication

[CmdletBinding()]
param(
    [Parameter(Mandatory, Position = 0)]
    [string]$UserPrincipalName,

    [switch]$Transitive,

    [string]$OutputPath
)

Connect-MgGraph -Scopes 'User.Read.All', 'GroupMember.Read.All' -NoWelcome -ErrorAction Stop

try {
    # --- Find the user -------------------------------------------------------
    $id = [uri]::EscapeDataString($UserPrincipalName)
    try {
        $user = Invoke-MgGraphRequest -Method GET -Uri "/v1.0/users/$($id)?`$select=id,displayName,userPrincipalName" -ErrorAction Stop
    }
    catch {
        throw "User '$UserPrincipalName' was not found. $($_.Exception.Message)"
    }

    # --- Read every page of memberships --------------------------------------
    $relation = if ($Transitive) { 'transitiveMemberOf' } else { 'memberOf' }
    $uri      = "/v1.0/users/$($user.id)/$($relation)?`$top=999"
    $groups   = [System.Collections.Generic.List[object]]::new()

    while ($uri) {
        $page = Invoke-MgGraphRequest -Method GET -Uri $uri -ErrorAction Stop
        foreach ($entry in $page.value) {
            if ($entry.'@odata.type' -eq '#microsoft.graph.group') { $groups.Add($entry) }
        }
        $uri = $page.'@odata.nextLink'
    }

    # --- Describe each group -------------------------------------------------
    $result = foreach ($g in $groups) {
        $kind = if ($g.groupTypes -contains 'Unified')           { 'Microsoft 365' }
                elseif ($g.mailEnabled -and $g.securityEnabled)  { 'Mail-enabled security' }
                elseif ($g.mailEnabled)                          { 'Distribution list' }
                else                                             { 'Security' }
        [PSCustomObject]@{
            Group      = $g.displayName
            Type       = $kind
            Membership = if ($g.groupTypes -contains 'DynamicMembership') { 'Dynamic' } else { 'Assigned' }
            GroupId    = $g.id
        }
    }
    $result = @($result | Sort-Object Group)

    $scope = if ($Transitive) { 'direct and nested' } else { 'direct' }
    Write-Host "$($user.displayName) ($($user.userPrincipalName)) is a $scope member of $($result.Count) groups." -ForegroundColor Cyan
    $result | Format-Table -AutoSize

    if ($OutputPath) {
        $result | Export-Csv -Path $OutputPath -NoTypeInformation -Encoding UTF8
        Write-Host "Saved to $((Resolve-Path -Path $OutputPath).Path)" -ForegroundColor Green
    }
}
finally {
    Disconnect-MgGraph | Out-Null
}
Export-EntraGroups.ps1

Export Entra ID groups to CSV

Download Read the guide

First half of a tenant-to-tenant group copy: saves each group’s name, description, mail nickname, type, visibility and dynamic membership rule.

Graph permissions: Group.Read.All
Admin role: Any admin role that can read groups, such as Global Reader

View the code (57 lines)
<#
.SYNOPSIS
    Exports Microsoft Entra ID groups (the groups Intune apps and policies are assigned to)
    to a CSV file, so they can be recreated in another tenant.

.DESCRIPTION
    First half of a tenant-to-tenant group copy. For each group it saves the name,
    description, mail nickname, group type, visibility and, for dynamic groups, the
    membership rule. Import-EntraGroups.ps1 reads this file in the destination tenant.

    Members, owners and assignments are not exported.

.PARAMETER OutputPath
    Where to save the CSV file. Default: groups.csv in the current folder.

.EXAMPLE
    .\Export-EntraGroups.ps1 -OutputPath .\groups.csv

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Groups
    Permissions : Group.Read.All (delegated)
    Sign in to the SOURCE tenant when prompted.
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Groups

[CmdletBinding()]
param(
    [string]$OutputPath = '.\groups.csv'
)

Connect-MgGraph -Scopes 'Group.Read.All' -NoWelcome -ErrorAction Stop
Write-Host "Connected to tenant $((Get-MgContext).TenantId)" -ForegroundColor Cyan

$properties = 'Id', 'DisplayName', 'Description', 'MailNickname', 'MailEnabled', 'SecurityEnabled',
              'GroupTypes', 'Visibility', 'MembershipRule', 'MembershipRuleProcessingState'

$groups = @(Get-MgGroup -All -Property $properties -ErrorAction Stop)

$groups | ForEach-Object {
    [PSCustomObject]@{
        ObjectId                      = $_.Id
        DisplayName                   = $_.DisplayName
        Description                   = $_.Description
        MailNickname                  = $_.MailNickname
        MailEnabled                   = $_.MailEnabled
        SecurityEnabled               = $_.SecurityEnabled
        GroupTypes                    = $_.GroupTypes -join ';'
        Visibility                    = $_.Visibility
        MembershipRule                = $_.MembershipRule
        MembershipRuleProcessingState = $_.MembershipRuleProcessingState
    }
} | Export-Csv -Path $OutputPath -NoTypeInformation -Encoding UTF8

Write-Host "Exported $($groups.Count) groups to $((Resolve-Path -Path $OutputPath).Path)" -ForegroundColor Green

Disconnect-MgGraph | Out-Null
Import-EntraGroups.ps1

Recreate Entra ID groups in another tenant

Download Read the guide

Second half: recreates security and Microsoft 365 groups from the CSV, skips names that already exist and anything Graph can’t create, and saves an old-to-new group ID map for re-pointing assignments.

Graph permissions: Group.ReadWrite.All
Admin role: Groups Administrator

View the code (124 lines)
<#
.SYNOPSIS
    Recreates Microsoft Entra ID groups from a CSV made by Export-EntraGroups.ps1.

.DESCRIPTION
    Second half of a tenant-to-tenant group copy. Run it while signed in to the
    DESTINATION tenant. For each row it creates a security group or Microsoft 365
    group with the same name, description, mail nickname, visibility and (for
    dynamic groups) membership rule.

    It skips:
      - groups whose name already exists in the destination tenant, so the script
        is safe to run again;
      - distribution lists and mail-enabled security groups, because Microsoft Graph
        cannot create them (create them in Exchange Online instead).

    It also writes <CsvPath>-id-map.csv with the old and new group IDs, which helps
    when you recreate Intune assignments.

    Run it with -WhatIf first to see what would be created.

.PARAMETER CsvPath
    Path to the CSV file created by Export-EntraGroups.ps1.

.EXAMPLE
    .\Import-EntraGroups.ps1 -CsvPath .\groups.csv -WhatIf

.EXAMPLE
    .\Import-EntraGroups.ps1 -CsvPath .\groups.csv

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Groups
    Permissions : Group.ReadWrite.All (delegated)
    Members and owners are not copied.
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Groups

[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)]
    [ValidateScript({ Test-Path -Path $_ -PathType Leaf })]
    [string]$CsvPath
)

$rows = @(Import-Csv -Path $CsvPath)
if ($rows.Count -eq 0) {
    throw "The CSV file '$CsvPath' is empty."
}

Connect-MgGraph -Scopes 'Group.ReadWrite.All' -NoWelcome -ErrorAction Stop
Write-Host "Connected to tenant $((Get-MgContext).TenantId)" -ForegroundColor Cyan

$created = 0; $skipped = 0; $failed = 0
$idMap = New-Object System.Collections.Generic.List[object]

foreach ($row in $rows) {
    $name = $row.DisplayName
    if (-not $name) { continue }

    $groupTypes      = @($row.GroupTypes -split ';' | Where-Object { $_ })
    $mailEnabled     = ($row.MailEnabled -eq 'True')
    $securityEnabled = ($row.SecurityEnabled -eq 'True')

    # Microsoft Graph can only create Microsoft 365 groups and security groups.
    if ($mailEnabled -and ($groupTypes -notcontains 'Unified')) {
        Write-Warning "Skipped '$name': distribution lists and mail-enabled security groups must be created in Exchange Online."
        $skipped++
        continue
    }

    # Do not create a second group with the same name.
    $filterName = $name -replace "'", "''"
    $existing = Get-MgGroup -Filter "displayName eq '$filterName'" -Top 1 -ErrorAction SilentlyContinue
    if ($existing) {
        Write-Host "Skipped '$name': a group with this name already exists." -ForegroundColor DarkGray
        $skipped++
        continue
    }

    # Mail nickname is required. Make one from the name if the CSV has none.
    $mailNickname = $row.MailNickname
    if (-not $mailNickname) {
        $mailNickname = ($name -replace '[^a-zA-Z0-9]', '')
        if (-not $mailNickname) { $mailNickname = 'group' + (Get-Random -Maximum 999999) }
    }

    $params = @{
        DisplayName     = $name
        MailNickname    = $mailNickname
        MailEnabled     = $mailEnabled
        SecurityEnabled = $securityEnabled
    }
    if ($groupTypes.Count -gt 0) { $params.GroupTypes = $groupTypes }
    if ($row.Description -and $row.Description -ne '.') { $params.Description = $row.Description }
    if ($row.Visibility) { $params.Visibility = $row.Visibility }
    if ($row.MembershipRule) {
        $params.MembershipRule = $row.MembershipRule

<#
.SYNOPSIS
    Adds (or removes) one account as Site Collection Administrator on every OneDrive
    in the tenant.

.DESCRIPTION
    Global and SharePoint administrators cannot open another user's OneDrive until
    they are a Site Collection Administrator on it. This script lists every OneDrive
    (personal site) in the tenant and grants that right to one account, so a bulk
    export such as Export-OneDriveFiles.ps1 can read the files.

    When the export is finished, run it again with -Remove to take the access away.

    Run it with -WhatIf first to see which OneDrives would change.

.PARAMETER AdminUrl
    Your SharePoint admin centre URL, for example https://contoso-admin.sharepoint.com

.PARAMETER UserPrincipalName
    The account to add (or remove) as Site Collection Administrator.

.PARAMETER Remove
    Removes the account as Site Collection Administrator instead of adding it.

.EXAMPLE
    .\Add-OneDriveSiteAdmin.ps1 -AdminUrl https://contoso-admin.sharepoint.com -UserPrincipalName admin@contoso.com -WhatIf
    Dry run: lists the OneDrives that would change.

.EXAMPLE
    .\Add-OneDriveSiteAdmin.ps1 -AdminUrl https://contoso-admin.sharepoint.com -UserPrincipalName admin@contoso.com -Remove
    Takes the access away again after the export.

.NOTES
    Author     : Kamruzzaman Akib
    Module     : Microsoft.Online.SharePoint.PowerShell (run it in Windows PowerShell 5.1)
    Admin role : SharePoint Administrator or Global Administrator
    Access to personal files is sensitive. Get written approval first, and remove
    the access as soon as the work is done.
#>
#Requires -Modules Microsoft.Online.SharePoint.PowerShell

[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)]
    [ValidatePattern('^https://[\w-]+-admin\.sharepoint\.[a-z.]+/?$')]
    [string]$AdminUrl,

    [Parameter(Mandatory)]
    [string]$UserPrincipalName,

    [switch]$Remove
)

Connect-SPOService -Url $AdminUrl -ErrorAction Stop

Write-Host 'Listing every OneDrive in the tenant. This can take a few minutes...' -ForegroundColor Cyan
$sites = @(Get-SPOSite -IncludePersonalSite $true -Limit All -Filter "Url -like '-my.sharepoint.com/personal/'" -ErrorAction Stop)
Write-Host "Found $($sites.Count) OneDrives." -ForegroundColor Cyan

$grant  = -not $Remove
$action = if ($grant) { 'Add as Site Collection Administrator' } else { 'Remove as Site Collection Administrator' }
$changed = 0
$failed  = 0
$i       = 0

foreach ($site in $sites) {
    $i++
    Write-Progress -Activity $action -Status $site.Url -PercentComplete ($i / $sites.Count * 100)

    if (-not $PSCmdlet.ShouldProcess($site.Url, "$action ($UserPrincipalName)")) { continue }

    try {
        $null = Set-SPOUser -Site $site.Url -LoginName $UserPrincipalName -IsSiteCollectionAdmin $grant -ErrorAction Stop
        $changed++
        Write-Verbose "Done: $($site.Url)"
    }
    catch {
        $failed++
        Write-Warning "Failed on $($site.Url): $($_.Exception.Message)"
    }
}
Write-Progress -Activity $action -Completed

Write-Host ''
Write-Host "OneDrives found : $($sites.Count)"
Write-Host "Changed         : $changed" -ForegroundColor Green
if ($failed) { Write-Host "Failed          : $failed" -ForegroundColor Red }
if ($grant -and $changed) {
    Write-Host 'When the export is finished, run this again with -Remove to take the access away.' -ForegroundColor Yellow
}

Export-OneDriveFiles.ps1

Download OneDrive files for one user, a CSV list or everyone

Download Read the guide

Downloads every file and keeps the folder structure, one folder per user. Reads every page of large folders, skips files already downloaded so you can resume, and ends with a summary. Replaces my three earlier export scripts.

Graph permissions: Files.Read.All, User.Read.All
Admin role: SharePoint Administrator or Global Administrator, plus Site Collection Administrator on each OneDrive

View the code (181 lines)
<#
.SYNOPSIS
    Downloads users' OneDrive files to a local folder, keeping the folder structure.

.DESCRIPTION
    Built for a tenant migration, where every OneDrive had to be exported before the
    old tenant was closed. Choose who to export in one of three ways:

      -UserPrincipalName   one or more users
      -CsvPath             a CSV file with a UserPrincipalName (or UPN) column
      -AllUsers            every member account in the tenant (guests are skipped)

    Each user's files are saved to <ExportPath>\<UPN>\ with the same folders as in
    OneDrive. Files that are already there with the same size are skipped, so you can
    stop the script and run it again to carry on where it left off.

    You must be Site Collection Administrator on each OneDrive first (see
    Add-OneDriveSiteAdmin.ps1), otherwise that OneDrive is reported as not accessible.

.PARAMETER UserPrincipalName
    One or more users to export.

.PARAMETER CsvPath
    A CSV file with a column named UserPrincipalName or UPN.

.PARAMETER AllUsers
    Export every member account in the tenant.

.PARAMETER ExportPath
    Local folder to save the files in. It is created if it does not exist.

.EXAMPLE
    .\Export-OneDriveFiles.ps1 -UserPrincipalName alex.wilber@contoso.com -ExportPath D:\OneDriveExport

.EXAMPLE
    .\Export-OneDriveFiles.ps1 -CsvPath .\users.csv -ExportPath D:\OneDriveExport

.EXAMPLE
    .\Export-OneDriveFiles.ps1 -AllUsers -ExportPath D:\OneDriveExport

.NOTES
    Author      : Kamruzzaman Akib
    Modules     : Microsoft.Graph.Authentication, Microsoft.Graph.Users, Microsoft.Graph.Files
    Permissions : Files.Read.All, User.Read.All (delegated)
    Replaces my three earlier scripts (single user, CSV list, whole organisation).
    OneNote notebooks are listed as not exported: export them from OneNote instead.
    Paths longer than 260 characters can fail unless Windows long paths are enabled.
#>
#Requires -Modules Microsoft.Graph.Authentication, Microsoft.Graph.Users, Microsoft.Graph.Files

[CmdletBinding(DefaultParameterSetName = 'User')]
param(
    [Parameter(Mandatory, ParameterSetName = 'User')]
    [string[]]$UserPrincipalName,

    [Parameter(Mandatory, ParameterSetName = 'Csv')]
    [ValidateScript({ Test-Path -Path $_ -PathType Leaf })]
    [string]$CsvPath,

    [Parameter(Mandatory, ParameterSetName = 'All')]
    [switch]$AllUsers,

    [Parameter(Mandatory)]
    [string]$ExportPath
)

$stats      = @{ Files = 0; AlreadyThere = 0; Failed = 0; Bytes = 0 }
$notExported = [System.Collections.Generic.List[string]]::new()

function Save-DriveFolder {
    param(
        [string]$DriveId,
        [string]$ItemId,
        [string]$LocalPath,
        [switch]$IsRoot
    )
    New-Item -ItemType Directory -Path $LocalPath -Force | Out-Null

    try {
        # -All follows paging. Without it, folders with more than 200 items are cut short.
        $children = Get-MgDriveItemChild -DriveId $DriveId -DriveItemId $ItemId -All -ErrorAction Stop
    }
    catch {
        if ($IsRoot) { throw }
        $script:stats.Failed++
        Write-Warning "Could not list $($LocalPath): $($_.Exception.Message)"
        return
    }

    foreach ($item in $children) {
        $target = Join-Path -Path $LocalPath -ChildPath $item.Name

        if ($item.Folder) {
            Save-DriveFolder -DriveId $DriveId -ItemId $item.Id -LocalPath $target
        }
        elseif ($item.File) {
            if ((Test-Path -LiteralPath $target) -and (Get-Item -LiteralPath $target).Length -eq $item.Size) {
                $script:stats.AlreadyThere++
                continue
            }
            try {
                Get-MgDriveItemContent -DriveId $DriveId -DriveItemId $item.Id -OutFile $target -ErrorAction Stop
                $script:stats.Files++
                $script:stats.Bytes += $item.Size
                Write-Verbose "Downloaded $target"
            }
            catch {
                $script:stats.Failed++
                Write-Warning "Could not download $($target): $($_.Exception.Message)"
            }
        }
        else {
            # OneNote notebooks and other packages are not plain files
            $notExported.Add($target)
        }
    }
}

# --- Connect and work out who to export --------------------------------------
Connect-MgGraph -Scopes 'Files.Read.All', 'User.Read.All' -NoWelcome -ErrorAction Stop

switch ($PSCmdlet.ParameterSetName) {
    'User' {
        $upns = $UserPrincipalName
    }
    'Csv' {
        $rows = @(Import-Csv -Path $CsvPath)
        if ($rows.Count -eq 0) { throw "The CSV file '$CsvPath' is empty." }
        $column = $rows[0].PSObject.Properties.Name |
            Where-Object { $_ -in 'UserPrincipalName', 'UPN' } |
            Select-Object -First 1
        if (-not $column) { throw 'The CSV file needs a column named UserPrincipalName or UPN.' }
        $upns = $rows.$column | Where-Object { $_ } | ForEach-Object { $_.Trim() }
    }
    'All' {
        $upns = Get-MgUser -All -Filter "userType eq 'Member'" -Property UserPrincipalName -ErrorAction Stop |
            Select-Object -ExpandProperty UserPrincipalName
    }
}
$upns = @($upns | Sort-Object -Unique)
Write-Host "Users to export: $($upns.Count)" -ForegroundColor Cyan
New-Item -ItemType Directory -Path $ExportPath -Force | Out-Null

# --- Export each OneDrive ----------------------------------------------------
$usersDone    = 0
$usersSkipped = [System.Collections.Generic.List[string]]::new()
$i = 0

foreach ($upn in $upns) {
    $i++
    Write-Progress -Activity 'Exporting OneDrives' -Status "$upn ($i of $($upns.Count))" -PercentComplete ($i / $upns.Count * 100)

    try {
        $drive = Get-MgUserDefaultDrive -UserId $upn -ErrorAction Stop
        Write-Host "Exporting $upn" -ForegroundColor Cyan
        Save-DriveFolder -DriveId $drive.Id -ItemId 'root' -LocalPath (Join-Path -Path $ExportPath -ChildPath $upn) -IsRoot
        $usersDone++
    }
    catch {
        $usersSkipped.Add($upn)
        Write-Warning "Skipped $($upn): no OneDrive, or you are not Site Collection Administrator on it. $($_.Exception.Message)"
    }
}
Write-Progress -Activity 'Exporting OneDrives' -Completed

# --- Summary -----------------------------------------------------------------
Write-Host ''
Write-Host "Users exported   : $usersDone of $($upns.Count)" -ForegroundColor Green
Write-Host "Files downloaded : $($stats.Files) ($([math]::Round($stats.Bytes / 1GB, 2)) GB)"
Write-Host "Already there    : $($stats.AlreadyThere)"
if ($stats.Failed) { Write-Host "Failed           : $($stats.Failed) (see the warnings above, then run again)" -ForegroundColor Red }
if ($usersSkipped.Count) {
    Write-Host "Users skipped    : $($usersSkipped -join ', ')" -ForegroundColor Yellow
}
if ($notExported.Count) {
    Write-Host "Not exported (OneNote notebooks or other packages): $($notExported.Count)" -ForegroundColor Yellow
    $notExported | ForEach-Object { Write-Host "  $_" }
}
Write-Host "Files are in $((Resolve-Path -Path $ExportPath).Path)"

Disconnect-MgGraph | Out-Null

New-ADUserFromTemplate.ps1

Create a new AD user by copying a teammate

Download

My onboarding shortcut: type the name, pick the OU and a template user, and it builds a unique username, creates the account (password change forced at first sign-in), copies company, department and office, and adds the same groups. Shows everything first and supports -WhatIf.

Module: ActiveDirectory (RSAT), Windows PowerShell 5.1
Admin role: Rights to create users in the OU and change membership of the copied groups

View the code (200 lines)
<#
.SYNOPSIS
    Creates an on-premises Active Directory user by copying a template user from the
    same OU.

.DESCRIPTION
    The onboarding shortcut I used for new joiners. You type the first and last name,
    pick the OU and a template user (someone in the same team), and the script:

      - builds a unique username (first initial + last name, then 1, 2, 3... if taken),
        removing accents and punctuation (Jose O'Brien -> jobrien)
      - creates the account with the UPN and email address set, and forces a password
        change at first sign-in
      - copies Company, Department and Office from the template user
      - adds the new user to the same groups as the template user

    It shows what it is about to do before it does it. Run it with -WhatIf for a dry run.

.PARAMETER SearchBase
    Distinguished name of the OU that holds your user OUs, for example
    "OU=Staff,DC=corp,DC=contoso,DC=com". Default: the whole domain.

.PARAMETER UpnSuffix
    The part after @ in the new user's UPN and email address, for example contoso.com.
    Default: the domain's DNS name.

.PARAMETER FirstName
    Optional. You are asked for it if you leave it out.

.PARAMETER LastName
    Optional. You are asked for it if you leave it out.

.EXAMPLE
    .\New-ADUserFromTemplate.ps1 -SearchBase "OU=Staff,DC=corp,DC=contoso,DC=com" -UpnSuffix contoso.com -WhatIf

.EXAMPLE
    .\New-ADUserFromTemplate.ps1 -UpnSuffix contoso.com -FirstName Alex -LastName Wilber

.NOTES
    Author : Kamruzzaman Akib
    Module : ActiveDirectory (RSAT), Windows PowerShell 5.1
    Rights : create users in the chosen OU and change membership of the copied groups
    The OU and template pickers use Out-GridView.
    The password is typed as a secure string and is never shown or saved.
#>
#Requires -Modules ActiveDirectory

[CmdletBinding(SupportsShouldProcess)]
param(
    [string]$SearchBase,
    [string]$UpnSuffix,
    [string]$FirstName,
    [string]$LastName
)

$domain = Get-ADDomain -ErrorAction Stop
if (-not $SearchBase) { $SearchBase = $domain.DistinguishedName }
if (-not $UpnSuffix)  { $UpnSuffix  = $domain.DNSRoot }

# Use one domain controller for every step, so the new account is never
# "not found" because of replication delay.
$server = $domain.PDCEmulator

function ConvertTo-UsernamePart {
    param([string]$Text)
    # Remove accents (an accented e becomes e), then anything that is not a letter (O'Brien -> OBrien)
    $decomposed = $Text.Normalize([Text.NormalizationForm]::FormD)
    $letters = $decomposed.ToCharArray() | Where-Object {
        [Globalization.CharUnicodeInfo]::GetUnicodeCategory($_) -ne [Globalization.UnicodeCategory]::NonSpacingMark
    }
    (-join $letters).ToLower() -replace '[^a-z]', ''
}

function New-UniqueUsername {
    param([string]$First, [string]$Last)
    $f = ConvertTo-UsernamePart $First
    $l = ConvertTo-UsernamePart $Last
    if (-not $f -or -not $l) { throw 'The first and last name must contain letters.' }

    # sAMAccountName allows 20 characters; keep room for a number on the end
    $base = $f.Substring(0, 1) + $l
    if ($base.Length -gt 17) { $base = $base.Substring(0, 17) }

    $candidate = $base
    $n = 0
    while (Get-ADUser -Server $server -Filter "SamAccountName -eq '$candidate' -or UserPrincipalName -eq '$candidate@$UpnSuffix'") {
        $n++
        $candidate = "$base$n"
    }
    $candidate
}

# --- Names -----------------------------------------------------------------------
if (-not $FirstName) { $FirstName = Read-Host 'First name' }
if (-not $LastName)  { $LastName  = Read-Host 'Last name' }
$FirstName = $FirstName.Trim()
$LastName  = $LastName.Trim()

# --- Pick the OU and the template user ----------------------------------------------
$ou = Get-ADOrganizationalUnit -Server $server -Filter * -SearchBase $SearchBase |
    Sort-Object DistinguishedName |
    Select-Object Name, DistinguishedName |
    Out-GridView -Title 'Pick the OU for the new user' -OutputMode Single
if (-not $ou) { Write-Warning 'No OU picked. Nothing was created.'; return }

$candidates = @(Get-ADUser -Server $server -Filter 'Enabled -eq $true' -SearchBase $ou.DistinguishedName -SearchScope OneLevel -Properties Title, Department)
$template = $null
if ($candidates.Count -eq 0) {
    Write-Warning 'There are no enabled users in this OU to copy, so no groups will be copied.'
}
else {
    $pick = $candidates |
        Sort-Object Name |
        Select-Object Name, SamAccountName, Title, Department, DistinguishedName |
        Out-GridView -Title 'Pick a template user (someone in the same role or team)' -OutputMode Single
    if (-not $pick) { Write-Warning 'No template user picked. Nothing was created.'; return }
    $template = Get-ADUser -Server $server -Identity $pick.DistinguishedName -Properties MemberOf, Company, Department, Office
}
$groups = if ($template) { @($template.MemberOf) } else { @() }

# --- Build the account details ------------------------------------------------------
$username    = New-UniqueUsername -First $FirstName -Last $LastName
$upn         = "$username@$UpnSuffix"
$displayName = "$FirstName $LastName"

# The object name (CN) must be unique inside the OU
$cn = $displayName
$escapedName = $displayName -replace "'", "''"
if (Get-ADUser -Server $server -Filter "Name -eq '$escapedName'" -SearchBase $ou.DistinguishedName -SearchScope OneLevel) {
    $cn = "$displayName ($username)"
}

Write-Host ''
Write-Host 'About to create:' -ForegroundColor Cyan
[PSCustomObject]@{
    Name     = $cn
    Username = $username
    UPN      = $upn
    OU       = $ou.DistinguishedName
    Template = if ($template) { $template.Name } else { '(none)' }
    Groups   = $groups.Count
} | Format-List

if (-not $PSCmdlet.ShouldProcess($upn, "Create user in $($ou.DistinguishedName)")) { return }

$password = Read-Host 'Initial password (the user must change it at first sign-in)' -AsSecureString

$newUser = @{
    Server                = $server
    Name                  = $cn
    GivenName             = $FirstName
    Surname               = $LastName
    DisplayName           = $displayName
    SamAccountName        = $username
    UserPrincipalName     = $upn
    EmailAddress          = $upn
    Path                  = $ou.DistinguishedName
    AccountPassword       = $password
    Enabled               = $true
    ChangePasswordAtLogon = $true
    PassThru              = $true
    ErrorAction           = 'Stop'
}
if ($template) {
    foreach ($attribute in 'Company', 'Department', 'Office') {
        if ($template.$attribute) { $newUser[$attribute] = $template.$attribute }
    }
}

try {
    $created = New-ADUser @newUser
}
catch {
    Write-Warning "The user was not created: $($_.Exception.Message)"
    Write-Warning 'If the message is about the password, the account may exist but be disabled. Reset its password and enable it in Active Directory Users and Computers.'
    return
}
Write-Host "Created $upn in $($ou.DistinguishedName)." -ForegroundColor Green

# --- Copy the template user's groups -------------------------------------------------
$added  = 0
$failed = 0
foreach ($group in $groups) {
    try {
        Add-ADGroupMember -Server $server -Identity $group -Members $created -ErrorAction Stop
        $added++
    }
    catch {
        $failed++
        Write-Warning "Could not add to $($group): $($_.Exception.Message)"
    }
}
if ($template) {
    Write-Host "Added to $added of $($groups.Count) groups copied from $($template.Name)." -ForegroundColor Green
}
if ($failed) { Write-Host "$failed groups failed. Add those by hand." -ForegroundColor Yellow }

Write-Host ''
Write-Host "Sign-in name for the new user: $upn" -ForegroundColor Cyan
Write-Host 'Give them the password you typed through a secure channel. They must change it at first sign-in.'
