Reimage a laptop from USB and enrol it into Microsoft Intune

Step-by-step reinstall of Windows 11 Pro from a bootable USB on a Lenovo ThinkPad, then joining the device to Microsoft Entra ID / Intune through the work-or-school OOBE flow, enabling Secure Boot and forcing a policy sync.

By Kamruzzaman Akib · 7 min read

  • Windows 11
  • Intune
  • Entra ID
  • Lenovo
  • Secure Boot
About this article. I originally wrote this guide for my company’s internal knowledge base. This public version has company names, colleagues’ names and email addresses, internal domains and system details removed. Screenshots are shown at full size: click any of them to enlarge. Only the parts that showed people or company information are blurred. Example addresses use Microsoft’s fictional contoso.com domain.

I wrote this guide for end users and regional IT staff who had to move laptops into a new company's Intune tenant. It is also the fix when a device runs Windows 10 or Windows 11 Home, which cannot join Entra ID. The device is wiped, Windows 11 Pro is installed, and the user's first sign-in enrols it into Intune automatically.

Before you start: you need a bootable Windows 11 stick. See Create a bootable Windows 11 USB. Back up anything on the laptop that isn't already synced to OneDrive. This process erases the disk.

Part 1: Install Windows 11 Pro

  1. Insert the bootable USB stick and power on the laptop.
  2. On a ThinkPad, when the prompt “To interrupt normal startup, press Enter” appears, keep pressing Enter until the Startup Interrupt Menu opens, then press F12 to choose a temporary boot device. If Windows boots normally, shut down and try again. Other brands use a different key for the boot menu.
  3. If the laptop asks for a BIOS password, stop and contact your IT team.
  4. In the Boot Menu, choose the USB flash drive.
  5. The laptop boots into Windows Setup. Choose your language and keyboard.
  6. Select Install Windows 11 and tick the box agreeing that everything will be deleted. If you are offered a list of editions, choose Windows 11 Pro.
  7. Accept the licence terms.
  8. Choose the internal disk, not the USB stick. The easiest way to tell is the size: the internal disk is usually 400 GB+ or 900 GB+, depending on the model.
  9. Check the summary. It should say Install Windows 11 Pro and Keep nothing. Click Install.
  10. Installation starts. The laptop restarts several times. This is normal.

Part 2: Out-of-box setup and Intune enrolment

  1. When installation finishes, you'll see the network screen. Connect to Wi-Fi, then confirm region, language and keyboard.
  2. Windows checks for updates, may restart, and then asks you to name the device. You can skip this; Intune can apply the naming standard later.
  3. Choose Set up for work or school.
  4. Sign in with your work account. This Entra-joins the device and enrols it into Intune.
  5. After sign-in you land on the desktop. Wait about 15 minutes while company apps and policies install, then restart.

Part 3: Turn Secure Boot back on

  1. Restart and press F1 at the Lenovo logo to enter the BIOS.
  2. Go to Security → Secure Boot and switch Secure Boot On.
  3. Press F10 and choose Yes to save and exit.

Part 4: Force a sync with Intune

If required apps don't appear, push a sync instead of waiting for the next check-in:

  1. Open Settings and search for Access work or school.
  2. Expand your work account and click Info.
  3. Click Sync.
  4. Required software (for example Chrome and Microsoft 365 apps) now installs. When the Chrome icon appears on the desktop, installation has started. Edge is already included with Windows 11.
