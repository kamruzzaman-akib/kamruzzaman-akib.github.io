Bulk create distribution groups in Exchange Online from a CSV

Create many Exchange Online distribution lists in one run, with owners, members and notes, from a CSV using the ExchangeOnlineManagement module. Each group is reported as SUCCESS or FAILED.

By Kamruzzaman Akib · 5 min read

  • PowerShell
  • Exchange Online
  • Distribution lists
  • Automation
About this article. I originally wrote this guide for my company’s internal knowledge base. This public version has company names, colleagues’ names and email addresses, internal domains and system details removed. Screenshots are shown at full size: click any of them to enlarge. Only the parts that showed people or company information are blurred. Example addresses use Microsoft’s fictional contoso.com domain.

This tutorial creates distribution groups in bulk from a CSV file with the ExchangeOnlineManagement module. It's useful when a team, office or newly acquired company needs a set of mailing lists created consistently.

Don't use PowerShell ISE for this. Connect-ExchangeOnline often fails inside ISE with a “window handle must be configured” error (see Microsoft Q&A). Use the standard Windows PowerShell or PowerShell 7 console.

Step 1: Prepare the CSV

The CSV has five columns:

  • Name: the display name of the group, for example HR Communications.
  • PrimarySmtpAddress: the group's email address, for example hr@contoso.com.
  • Owners: one or more owner addresses, separated by commas.
  • Members: one or more member addresses, separated by commas.
  • Notes: the group description, for example Official communication channel for the HR team.

Step 2: Install the module and connect

  1. Open a standard PowerShell window (run as administrator for the install) and run: 
    Install-Module -Name ExchangeOnlineManagement
    Type A and press Enter to confirm installing from PSGallery.
  2. Connect and sign in with an account that has the Exchange Administrator (or Global Administrator) role: 
    Connect-ExchangeOnline

Step 3: Run the script

Paste this into the same window, after changing the CSV path. It splits the owner and member lists, creates each group and prints SUCCESS or FAILED with the reason:

$groups = Import-Csv -Path "C:\Scripts\groups.csv"

foreach ($group in $groups) {
    # Split the comma-separated strings into arrays, trim spaces and drop empty entries
    $ownersArray  = $group.Owners  -split ',' | ForEach-Object { $_.Trim() } | Where-Object { -not [string]::IsNullOrEmpty($_) }
    $membersArray = $group.Members -split ',' | ForEach-Object { $_.Trim() } | Where-Object { -not [string]::IsNullOrEmpty($_) }

    try {
        Write-Host "Processing group: $($group.Name)"
        New-DistributionGroup -Name $group.Name `
            -PrimarySmtpAddress $group.PrimarySmtpAddress `
            -ManagedBy $ownersArray `
            -Members $membersArray `
            -Notes $group.Notes `
            -ErrorAction Stop
        Write-Host "SUCCESS: Created $($group.Name)" -ForegroundColor Green
    }
    catch {
        Write-Host "FAILED: Could not create $($group.Name)." -ForegroundColor Red
        Write-Host "Error: $($_.Exception.Message)" -ForegroundColor Red
    }
}

Step 4: Verify

Open the Exchange admin center → Groups and check the Distribution list tab.
